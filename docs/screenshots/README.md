Drop four PNGs here, named exactly:

| File | View | URL |
|---|---|---|
| `feed.png` | Feed, signed in, composer visible | `/` |
| `post.png` | A post with its replies and the reply box | `/posts/:id` — pick one with several comments |

| `profile.png` | Another user's profile, with the Follow button | `/users/:id` |

Take them at a window width of ~1280px so the sidebar is in frame, and crop
to the page content — no browser chrome, tabs or bookmarks bar.
